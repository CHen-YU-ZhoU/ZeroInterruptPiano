# ZeroInterruptPiano（零断奏钢琴）

面向 Android 设备的 21 键 / 36 键游戏自动演奏钢琴工具，通过本地 JSON-RPC 桥接 **ZeroInterruptClicker（零断触连点器）** 的底层硬件触控注入引擎（16-Slot 并发），实现高精度多指和弦演奏，不抢占物理触控。

---

## 核心特性

- **双键盘模式**：支持 **21 键（3×7 自然音阶）** 与 **36 键（3×12 完整半音阶，含 15 个黑键/升降音）** 一键切换，曲库自动按模式分目录管理。
- **双校准方式 + 多游戏方案**：
  - **网格悬浮校准**：拖动/缩放 3×7（或 36 键）校准框并支持点键透传试音。
  - **手动逐音拾取**：按音高顺序逐次引导拾取每个琴键（支持按住十字准星瞄准、松手落点、拖动圆点微调、撤销/跳过与试音）。
  - **多方案命名与切换**：可按游戏名称（如原神、光遇、心动小镇等）保存多套布局，支持在主界面与悬浮播放条内一键切换。
- **本地乐谱导入与播放控制**：内置多首经典钢琴曲，支持导入 `.mid` / `.midi` / `.mxl` / `.musicxml` / `.json`，支持 0.5x–2.0x 实时变速、进度拖动、悬浮播放条及导出连点器 Bundle JSON。

## 使用前准备（依赖与连接配置）

本软件依赖 **ZeroInterruptClicker（零断触连点器）** 与 **Shizuku** 提供底层触控注入能力，首次使用请按以下步骤完成连接：

1. **配置连点器**：
   - 安装并打开 **ZeroInterruptClicker**，完成悬浮窗权限、Shizuku 授权与触控校准。
2. **开启连点器专业模式并获取 RPC Token**：
   - 在连点器中切换到 **「实验室」** 页面；
   - 连续点击底部的 **「版本号」7 次**，展开 **「专业模式」**；
   - 在展开的面板中找到 **「RPC 接口桥」**，开启开关并点击 **「复制 Token」**。
3. **在零断奏钢琴中填入 Token**：
   - 打开 **ZeroInterruptPiano**，切换到 **「连接与调优」**（横屏侧边栏为 **「设置」**）页面；
   - 找到 **「连点器 RPC 接口桥 (127.0.0.1:27183)」** 卡片；
   - 点击 **「粘贴 Token」** 填入刚才复制的 Access Token，随后点击 **「测试连接」**，提示连接成功且 `Shizuku=true` 即可使用。

> [!TIP]
> **HyperOS / MIUI 后台保活提醒**：切入游戏后，若连点器未开启悬浮窗且电池策略未设为「无限制」，系统可能在数秒后冻结连点器导致 RPC 超时。建议将连点器电池策略设为**无限制**，或保持连点器悬浮条（可收起贴边）处于开启状态。

## 快速上手

1. **选择键盘模式**：在「曲库与演奏」顶部选择 **21 键** 或 **36 键**。
2. **校准游戏琴键**：
   - 打开目标游戏并进入弹琴界面；
   - 点击 **「开启悬浮播放条」**，在悬浮条点击 **「校准」**，选择 **「网格校准」** 或 **「手动拾取」**；
   - 校准完成后点击 **「保存」**，输入游戏名称（如「心动小镇」）即可覆盖当前方案或另存为新方案。
3. **开始演奏 / 导入乐谱**：
   - 在主界面或悬浮播放条选择曲目，点击 **「播放」** 即可自动演奏；
   - 点击曲库右上角 **「导入 MIDI / MXL」**，选择目标键位模式后选取本地乐谱文件即可自动变调映射并入库。
